# Channelscaler Alternatives Guide

Standalone JazzHQ buyer’s guide with 10 product sections, comparison tables, buying guidance, and FAQs.

- `/` opens the guide at `/alternatives/channelscaler-alternatives`.
- `/alternatives` lists the Channelscaler guide.
- The guide uses `noindex` during editorial review.

Use Node 20 or later. Run `npm ci` and `npm run dev`. Run `npm run lint`, `npm run typecheck`, and `npm run build` to verify changes. A clean build requires access to Google Fonts.

Set `NEXT_PUBLIC_SITE_URL` to the site origin when configuring canonical metadata.
